# Sandip-Exam-hall-allocation-frontend
📘 Exam Hall Seating & Room Allocation System

A simple web-based application designed to manage exam hall seating arrangements and room allocation efficiently for universities.

🚀 Features
🔐 Faculty Login System
🧑‍🎓 Student Allocation Input (PRN & Division)
🏫 Room Allocation with Seating Configuration
🪑 Bench Arrangement Options:
2 students per bench
3 students per bench
Single seating
⚠️ Input Validation (Room number must be multiples of 10)
🎨 Clean and modern UI with responsive design
